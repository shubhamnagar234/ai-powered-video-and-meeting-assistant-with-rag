# ai-powered-video-and-meeting-assistant-with-rag
AI-powered Video &amp; Meeting Assistant with RAG that accepts YouTube URLs or audio/video files, transcribes English with Whisper AI and Hindi/Hinglish with Sarvam AI, generates summaries, extracts action items, decisions &amp; follow-ups, enables chat with meetings using ChromaDB, and exports reports as PDF/TXT.
